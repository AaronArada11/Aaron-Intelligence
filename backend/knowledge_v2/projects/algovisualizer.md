# AlgoVisualizer

## Overview

AlgoVisualizer is an interactive educational application that helps students and developers understand computer science algorithms through real-time animation and visual feedback. It includes sorting visualizations, pathfinding visualizations, interactive grid and wall placement, adjustable animation speed, and step-by-step execution.

Aaron built the project with React, JavaScript, CSS, and Vercel. The work strengthened his understanding of algorithm implementation, React state management, animation and rendering performance, interactive interface development, and educational software design.
