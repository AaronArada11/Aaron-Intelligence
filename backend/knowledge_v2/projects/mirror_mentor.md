# Mirror Mentor

## Overview

Mirror Mentor is an AI-powered educational platform built during ACM Developers Week. It helps students improve programming skills through guided Socratic questioning instead of immediately giving direct answers. The team placed fourth in the hackathon.

The stack used HTML, CSS, and JavaScript for the frontend; FastAPI for the backend; Supabase PostgreSQL and Supabase Auth; Gemini API; and Vercel. The analysis workflow moves through code understanding, observation and issue detection, Socratic questioning, and improvement suggestions.
